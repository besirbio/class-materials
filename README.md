# Class Materials: how to look after the site

**Student address:** shown under *Settings → Pages* on this repository (it looks like `https://YOUR-NAME.github.io/class-materials/`).

Every file goes in **`materials` → a grade folder → a topic folder**. Folder names become the grade and topic names, and file names become the titles students see. About **1 to 2 minutes** after any change, the site updates by itself. To watch it happen, open the **Actions** tab: a yellow dot means it is working, a green tick means it is done, and a red X means something went wrong.

## Add a file
1. Open `materials`, then the grade, then the topic.
2. Click **Add file** → **Upload files**.
3. Drag your files onto the page.
4. Click the green **Commit changes** button.

## Add a topic
1. Open `materials`, then the grade.
2. Click **Add file** → **Create new file**.
3. In the name box, type the topic name and then `/`. For example, `Fractions/` turns into a folder.
4. Then type `.keep` as the file name. Leave the big box empty. The site ignores this file.
5. Click **Commit changes…**, then **Commit changes** again.
6. Open the new topic folder and add files to it as shown above.

## Rename a file
GitHub's website can't rename PDF or PowerPoint files. Do it in two steps:
1. Rename the file on your computer, then upload it as shown in *Add a file*.
2. Delete the old copy as shown in *Delete a file*.

## Delete a file
1. Click the file to open it.
2. Click the **⋯** menu (top right) → **Delete file**.
3. Click **Commit changes…**, then **Commit changes** again.

To remove a whole topic, delete every file in it, `.keep` included. The empty folder then disappears.

## Good to know
- **Size limits:** you can drag in files of up to **25 MB** each. Keep the whole site under about **1 GB**.
- **Slides:** PowerPoint files download instead of opening. For slides that open on any phone, export them to PDF first (in PowerPoint: *File → Export → PDF*).
- **Privacy:** anyone with the address can see the materials. Only you can change them. **Never upload grades, student names or anything private.** Deleted files stay in this repository's history.
- **A student sees an old list?** Ask them to close the page and open it again.
- **Do not change** the `site` and `.github` folders or the `README.md` notes. The website runs on them.
